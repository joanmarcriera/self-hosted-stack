Automation Consultancy Stack

Run the operating system for a small modern company.

This stack is built to help a three-person SME automation team capture client demand, document delivery, coordinate work, and keep operational trust visible from one place. It is intentionally simple enough to reproduce on a single server and structured enough to grow into a repeatable client blueprint.

Example automation loop

A small client engagement should move from first signal to documented delivery without scattered tools.

1
Lead appears in EspoCRM and a workflow starts in n8n.
2
Discovery notes and SOPs are recorded in BookStack for reuse.
3
Delivery tasks are assigned in Vikunja while live service health and funnel telemetry stay visible in Grafana.

Platform surfaces

Each tool has a narrow job. The value comes from how they connect, not from any one app pretending to do everything.
